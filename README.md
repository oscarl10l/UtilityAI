 Utility AI - Clases 7 y 8

 Versión del motor

Motor: Unity
Versión: Unity 6000.3.7f1
Lenguaje: C#

Instrucciones para ejecutar

1. Abrir *Unity Hub*.
2. Seleccionar **Open / Add project**.
3. Seleccionar la carpeta de este repositorio.
4. Abrir el proyecto con la versión de Unity indicada.
5. Abrir la escena utilizada para la actividad.
6. Presionar **Play** para ejecutar la práctica.
7. Abrir Window > General > Console para observar las puntuaciones y acciones del NPC.

 Escena utilizada

Escena: SampleScene

Ubicación: Assets/Scenes/SampleScene.unity


La escena contiene el NPC, enemigo, recurso de salud, punto seguro y superficie navegable necesarios para ejecutar la práctica.

Controles necesarios

Esta práctica no requiere controles manuales.

El NPC ejecuta automáticamente el sistema de Utility AI al iniciar la escena mediante el botón Play.
